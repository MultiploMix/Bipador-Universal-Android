Nenhuma associação cadastrada.

EAN exclusivo por cor: cadastre o SKU completo para conferência automática. Se cadastrar apenas o SKU base, o aplicativo pedirá confirmação visual da variação do pedido, sem exigir cadastro de cores.

Preencha essas cores somente quando o mesmo EAN aparecer em várias variações. Se cada cor tiver EAN próprio, não precisa preencher estas opções: use o SKU completo para aprovação automática ou somente o SKU base para confirmação visual simples.

Importar / Exportar

CSV UTF-8 com colunas EAN, SKU, Produto, Cor, Tamanho, Variacoes. Para várias cores no mesmo EAN, use SKU base e informe as cores em Variacoes, ou cadastre uma linha por cor/tamanho.

Associações cadastradas

EAN único com SKU completo: aprovação automática. EAN apenas com SKU base: confirmação visual simples da variação esperada, sem exigir cadastro de cores. EAN compartilhado: escolha da variação. QR Code do produto continua com SKU completo. Os dados ficam neste navegador: faça backups.
